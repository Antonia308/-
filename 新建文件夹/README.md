# 一餐灵感

一个可离线使用的食材菜谱推荐 PWA，内置 93 道少油少盐家常菜，并可根据库存即时组合滑蛋、肉片、豆腐煲和蔬菜快炒。输入现有食材后，还能通过本机的 SQLite 菜谱数据库生成 7 天 × 午餐、晚餐 的一周食谱，并汇总本周需要补买的食材。另提供 7 组采购灵感、15 种常用食材的预处理查询，以及按菜名从 HowToCook 在线菜库检索。

## 在电脑上运行

需要安装 Node.js 22.5 或更新版本（一周食谱的服务器端使用内置的 node:sqlite）。在项目目录运行：

```powershell
npm start
```

浏览器打开 `http://localhost:4173`。不运行服务时，也可以直接打开 `index.html`，但离线缓存和安装功能需要通过网站地址访问；一周食谱在连不上服务时会自动用内置菜谱离线排，连上服务时则由服务器端的菜谱数据库排菜。

首次运行时若缺少菜谱数据，先运行：

```powershell
npm run db:sync
```

它会从 `index.html` 提取菜谱，生成 `data/recipes.json` 与 `data/flex-recipes.mjs`，并写入 SQLite 数据库 `data/recipes.db`（自动创建）。以后修改 `index.html` 里的菜谱后，重新运行 `npm run db:sync` 即可同步（需要强制重播种时加 `--force`）。

## 在手机上使用

**局域网访问**：电脑和手机连接同一 Wi-Fi 后，运行 `npm start`，在手机浏览器打开终端输出的手机访问地址（形如 `http://192.168.x.x:4173`；VPN 虚拟网卡的地址手机上访问不到）。此时一周食谱由电脑上的菜谱数据库排菜。

**独立安装（推荐）**：把项目部署到 HTTPS 静态网站后，手机上可安装为 PWA、完全脱离电脑使用：

1. 把整个项目文件夹推送到 GitHub 仓库（网页上传或 git 均可）；
2. 仓库页面进入 Settings → Pages → Source 选择 main 分支（根目录）→ Save；
3. 稍等几分钟得到地址 `https://你的用户名.github.io/仓库名/`，在手机浏览器打开；
4. Android 用 Chrome 的“安装应用”或“添加到主屏幕”；iPhone/iPad 用 Safari 的“分享”→“添加到主屏幕”。

部署版没有 Node 服务，生成一周食谱时会自动用内置菜谱离线排，其余四个功能照常离线可用；电脑上运行 `npm start` 时则优先走 SQLite 菜谱数据库。局域网 HTTP 地址只能浏览，浏览器出于安全限制不会启用 PWA 安装或 Service Worker。

## 数据说明

食材清单只保存在当前浏览器的本地存储中。热量、蛋白质、油和盐的数字为估算值，实际营养会因食材品种、品牌和称量方式变化。

一周食谱优先使用本机 SQLite 数据库（data/recipes.db），连不上服务时自动改用页面内置的同一套菜谱离线排（两种数据源内容一致，由 `npm run db:sync` 保持同步；排菜算法为同一份实现）。数据库只在运行服务时供本机页面查询，不向任何网络上传。生成的一周食谱会缓存在浏览器本地，断网后仍可查看上次结果。

HowToCook 菜库在联网时按需读取 GitHub 的公开目录，展开单道菜时才读取原文，不会把整个仓库下载到应用。候选是按菜名中的食材词匹配，未命中的食材可能不会出现在列表；原菜谱用量不一定适合减脂或低盐饮食，使用时请查看原料。断网时仍可使用内置菜谱和本地组合。
